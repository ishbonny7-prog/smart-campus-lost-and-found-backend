Project Description

This project is a REST API for managing lost and found items on campus. It manages owners , lost report, deskofficers, found desks, item categories,and return records.

Technologies Used 

.java 21
.Spring Boot
.Spring Data JPA
.PostgreSQL
.Maven
.Docker
.Visual Studion Code REST Client

How to Run the Project
1. Clone the  repository 
http://github.com/ishbonny7-prog/smart-campus-lost-and-found-backend.git

2. Open the project folder
cd smart-campus-lost-and-found-backend

3. Start PostgreSQL
docker compose up -d

4. Run the application
./mvnw spring-boot:run

5. Access the API
The API runs at:
http://localhost:8080

API Testing
The API endpoints are tested using the request.http file in the visual Studio code

to test and endpoint:
1. Open requests.hhtp in Visual Studio Code
2. Make sure the Spring Boot application is running.
3. Click Send Request above the HTTP request.
4. View the response in the VS Code response panel.
